## 1. Final calculation framework

I would structure your finalized route around these **8 primary factors**:

| Factor           | Required output | Calculation                                                        |
| ---------------- | --------------- | ------------------------------------------------------------------ |
| **Education**    | **Number**      | Schools + colleges within **100 m of HSR centerline**              |
| **Highways**     | **Number**      | NH + SH + MDR crossings/intersections                              |
| **Forest**       | **km²**         | Land intersected by **2 m permanent ground footprint**             |
| **Agriculture**  | **km²**         | Land intersected by **2 m footprint**                              |
| **Built-up**     | **km²**         | Built-up land intersected by **2 m footprint**                     |
| **Wetlands**     | **km²**         | Wetland intersected by **2 m footprint**                           |
| **Waterbodies**  | **km²**         | Waterbody intersected by **2 m footprint**                         |
| **ESZ**          | **km + number** | Perpendicular distance from centerline to each ESZ/NP/WLS boundary |
| **Route length** | **km**          | Complete HSR alignment length                                      |
| **Tunnels**      | **number + km** | Number of tunnel sections + cumulative tunnel length               |

### Important distinction

For the **land-use factors**, we should **not buffer the route by 17.5 m**.

You have specifically defined the permanent ground-level footprint as:

> **2 m**

So the calculation should be based on:

**HSR centerline → 2 m ground footprint → intersection with land-use polygons**

That gives the actual area occupied at ground level under your current modelling assumption.
